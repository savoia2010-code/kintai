# 打刻（案B）仕様

開始・終了報告を押した時刻を「宣言」として記録し、その日の始業・終業に自動で反映する。
タイムライン照合（[timeline-matching.md](timeline-matching.md)）は月末の確認と補完に使う。

## 守ること

- 打刻ログは追加だけにする（消さない・書き換えない）。座標は送らない・残さない。
- GAS を変えるときは、版を作って既存デプロイ（@11）を更新する。新しくデプロイして URL を変えない。
- 既存の受け口（`saveRecord` / `deleteRecord` / `notify` / `uploadFile` / `getRecords`）は変えない。

## 1. 打刻ログ（GAS・スプレッドシート）

- スプレッドシートに「打刻ログ」シートを1枚置く（全期間で1枚。無ければ見出し付きで作る）。
- 列：受信日時（GAS の時刻）／端末の時刻／日付／種別（開始・終了・到着・出発）／場所（リモート・出社・混在・空欄）／送り元（アプリ・ショートカット）。

### `punch`（doPost）

```json
{ "action": "punch", "key": "…", "type": "start | end | arrive | leave",
  "clientTime": "2026-11-27T09:12:00+09:00", "date": "2026-11-27",
  "location": "出社", "source": "app | shortcut", "message": "（任意）Chatwork に投稿する文面" }
```

- 先に打刻ログへ1行追加し、`message` があれば Chatwork に投稿する。
- `clientTime`・`date` が無いとき（ショートカット）は、受信日時（日本時間）から決める。
- 返り値：`{ "status": "ok", "receivedAt": "…" }`。失敗時は既存と同じく `{ "status": "error", "message": "…" }`。
- 送り直しで同じ打刻が2行になることがある。照合では、その日の最初の開始・最後の終了を使う。

### `getPunches`（doGet）

- `action=getPunches&month=YYYY-MM`（○月度、前月26日〜当月25日）→ `{ "status": "ok", "punches": [ { receivedAt, clientTime, date, type, location, source } ] }`

## 2. アプリの開始・終了報告

- ボタンを押すと、`punch`（`source: "app"`、Chatwork の文面つき）を1回送る。`notify` は使わない。
- Chatwork への投稿は、報告カードの「Chatwork にも投稿する」を入れたときだけ行う（`kintai_v1_chatwork_post`、既定は投稿しない）。外しているときは `message` を付けず、打刻ログへの追記と自動保存だけ行う。
- 失敗したらエラーを表示するだけ。未送信として送り直す仕組みは作らない（もう一度押すと、その時刻で打刻される）。
- 成功したときだけ、次の規則でその日の記録を**自動で保存する**。保存の経路は通常の保存と同じ（未送信の一覧に入り `saveRecord` で同期される）。

### 自動保存の規則

| 場面 | 動き |
|---|---|
| 開始報告・記録なし | 新しく作る：区分 出勤（土日は休日出勤）、始業＝押した時刻の30分切り捨て、終業 空欄、休憩 1:00、場所・作業内容はフォームの選択 |
| 開始報告・記録あり | 始業・場所・作業内容だけ書き換える |
| 終了報告・記録あり | 終業（30分切り捨て）と作業内容だけ書き換える。始業は変えない |
| 終了報告・記録なし | 終業だけ入れた記録を新しく作る |
| その日が年休・欠勤 | 記録は変えず「年休の記録があるため反映しませんでした」と表示（打刻と報告は送る） |
| 0:00〜4:59 の終了報告 | 前日の記録の終業として扱う |

- 終了報告の「実働：約○時間」は、自動保存した後の始業・終業・休憩から計算する。

## 3. 月末の確認（照合パネル）

- 照合パネルで `getPunches` を取得し、記録の始業・終業と、開始・終了の打刻（30分切り捨て）が違う日を候補に出す。反映の仕方は案Aと同じ。
- タイムラインを読み込まなくても、打刻との照合だけで使える。
- ショートカットの到着・出発は参考として表示する。

## 4. ショートカット（任意の補助）

- iPhone のオートメーション（会社に着いた／離れた）から `punch`（`type: arrive | leave`、`source: "shortcut"`、`message` なし）を送れる。Chatwork には投稿しない。
- 受け口は今回の GAS 更新で作る。ショートカットの設定は後で行う。
